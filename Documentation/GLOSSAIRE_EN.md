# Operational glossary

**Software:** CoDIR IA v17.0 — build `v17.4.3.62.13.9.4.65-M6B-B1.3.62.13.9.4.65`  
**Documentation revision:** 18 October 2026  
**Use:** supervised professional use

| Term | Meaning |
|---|---|
| Fact / actual | Statement about an observed state or event; its nature is distinct from evidence. |
| Confirmed on page | Software match to an attachment and page; verify the number and label, dimensions and context. |
| Declared, unconfirmed / [UNSOURCED] | Required match not established. Several causes are possible; the status does not identify which. Does not mean no source exists. |
| Brief declaration | User provenance; may contain a declared fact, assumption, target or previously approved decision, which must be distinguished. |
| Unsupported target | Desired or proposed result without the support required by the check; not an actual. |
| Brief target | Target written by management in the brief and quoted as a target; left as written in the body, flagged once at the top of the brief section and in the register. Neither certified nor achieved. |
| Reconciled / to verify | Outcome of the arithmetic check between confirmed facts of the same period, scope and currency (revenue − cost of sales = gross profit; gross profit − operating expenses = operating profit). Beyond a 1% gap, the published result becomes “to verify”; the published value is never replaced. |
| Non-quantity | A number that is not a magnitude: nomenclature number (Scope 3, ISO 9001), identifier (LEI, SIREN), name containing a number (« Model X-500 »), period marker (Q4, FY2025). |
| Literal sign | Preserve the source sign; do not automatically make negative net debt positive. |
| Balance / flow / movement / ratio | Distinct types; the same number on the same page does not make them interchangeable. |
| Register | List of flagged passages, kept in place, and control information available according to path; not a completeness certificate. |
| In-place flag | Passage kept as the agent wrote it, highlighted and followed by “⚠ to verify — reason”; counted in the first-page box. Keeping principle, with the exceptions described in the delivery doctrine. |
| Case memory | Local history and multi-meeting register; neither automatic approval nor model training. |
| PPTX draft | Editable support to complete from Word; incomplete may be acceptable, misleading is not. |
| A1, scores and checks | Coverage, evidence or usability indicators; never release approval. |
| Deterministic guard | Local rule with no model call for its decision; supports inspection, not guaranteed correctness. |
