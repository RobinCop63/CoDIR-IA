# Politique de sécurité — CoDIR IA / Security policy

**Signaler une vulnérabilité / Report a vulnerability :** écrivez à **security@vauquigneux.com** (canal principal / main channel). En cas d'indisponibilité / if unavailable : https://robinsauzet.com/contact/ (repli / fallback). Ne publiez pas le détail d'une vulnérabilité avant correction / Please do not disclose details publicly before a fix.

**Périmètre / Scope :** le logiciel CoDIR IA publié dans ce dépôt (application locale, lanceurs, scripts d'installation). Les services des fournisseurs d'IA et des registres publics relèvent de leurs propres politiques. / The CoDIR IA software published in this repository (local application, launchers, installation scripts). AI providers' and public registers' services are covered by their own policies.
