# CoDIR IA v16.3.3.22 — Notes de version / Release Notes

## 🇫🇷 Résumé

**Export PowerPoint professionnel — palette Navy / Or.**

### Points clés

- **PPT visuel** : refonte complète du rendu graphique — slides de présentation dignes d'un CoDIR ou ComEx
- **Rétrocompatible** : aucune modification de `app.py` nécessaire, même API interne
- **Nouveau module** `experimental/pptx_from_cr.py` : génère un deck stratégique 8 slides depuis un CR Word

### Format PPT v16.3.3.22

| Slide | Contenu | Design |
|-------|---------|--------|
| Titre | Deck title · Topic · Date | Fond Navy, barre or, décor géométrique |
| Contexte & objectifs | 3–5 bullets + reco | Fond clair, header Navy, carte blanche, bullets ronds or |
| Slides sujets (4–7) | 1 thème par slide, 3–5 bullets | Fond clair, badge numéroté, accent couleur cyclique |
| Plan d'action | 1 bullet par direction | Fond Navy, cartes avec badge direction coloré |

**Couleurs accents** : Teal (Stratégie) · Orange (Marketing) · Vert (Finance) · Or (DG)

### Compatibilité
- Windows 10/11 ✅
- macOS 12+ ✅
- Python 3.10, 3.11, 3.12 ✅
- Providers : OpenAI · Anthropic · Google/Gemini · Mistral ✅

## 🇬🇧 Summary

**Professional PowerPoint export — Navy / Gold palette.**

### Highlights

- **Visual PPT**: complete graphical redesign — slides worthy of a Board or Executive Committee meeting
- **Backward compatible**: no changes required in `app.py`, same internal API
- **New module** `experimental/pptx_from_cr.py`: generates a strategic 8-slide deck from a Word report

### PPT format v16.3.3.22

| Slide | Content | Design |
|-------|---------|--------|
| Title | Deck title · Topic · Date | Dark Navy bg, gold bar, geometric decor |
| Context & objectives | 3–5 bullets + recommendation | Light bg, Navy header, white card, gold oval bullets |
| Topic slides (4–7) | 1 theme/slide, 3–5 bullets | Light bg, numbered badge, cyclic accent color |
| Action plan | 1 bullet/function | Dark Navy bg, direction cards with color badge |

**Accent colors**: Teal (Strategy) · Orange (Marketing) · Green (Finance) · Gold (CEO/DG)

### Compatibility
- Windows 10/11 ✅
- macOS 12+ ✅
- Python 3.10, 3.11, 3.12 ✅
- Providers: OpenAI · Anthropic · Google/Gemini · Mistral ✅
