# 🍎 Launching CoDIR IA.app — Quick Guide

## Double-click CoDIR IA.app

1. The application checks the Python environment
2. Installs or updates dependencies if needed
3. Launches Streamlit in the background
4. Automatically opens your browser at `http://localhost:8501`

## If macOS blocks the application

**System Settings** > **Privacy & Security** > **Open Anyway**

*or* right-click > **Open** > **Open**

## Closing the application

Simply close the browser window, then quit the Terminal opened by the app.
