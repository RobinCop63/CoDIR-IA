# 🍎 Lancer CoDIR IA.app — Guide rapide

## Double-clic sur CoDIR IA.app

1. L'application vérifie l'environnement Python
2. Installe ou met à jour les dépendances si nécessaire
3. Lance Streamlit en arrière-plan
4. Ouvre automatiquement votre navigateur sur `http://localhost:8501`

## Si macOS bloque l'application

**Réglages Système** > **Confidentialité & sécurité** > **Ouvrir quand même**

*ou* clic droit > **Ouvrir** > **Ouvrir**

## Fermer l'application

Fermez simplement la fenêtre du navigateur, puis quittez le Terminal ouvert par l'app.
